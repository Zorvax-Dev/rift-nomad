# Rift Nomad

Action survival sci-fi réalisé avec Godot 4.

## Ouvrir le projet
1. Ouvre Godot 4.7 ou plus récent.
2. Importe le dossier du projet.
3. Lance `Main.tscn`.

## Contrôles
- Déplacement : clavier / joystick flottant
- Combat : automatique
- Menu : bouton HUD ou écran d'accueil

## Notes
- Sauvegarde automatique locale
- Pensé pour desktop et PWA / mobile paysage

## Export iPhone / PWA
Double-clique sur `EXPORT_IPHONE.command`. Le script exporte automatiquement le preset Web PWA, applique le cadrage Safari/iPhone, puis met à jour les fichiers GitHub Pages à la racine du dépôt.
