RIFT NOMAD - EXPORT IPHONE / PWA

Double-clique sur EXPORT_IPHONE.command.

La V48 cherche automatiquement Godot :
- dans /Applications et ~/Applications,
- via Homebrew,
- dans le PATH,
- via Spotlight,
- dans Téléchargements et le Bureau.

Si Godot n'est toujours pas trouvé, une fenêtre Finder s'ouvre pour te laisser sélectionner Godot.app manuellement. Le chemin est ensuite mémorisé dans .godot_path pour les exports suivants.

Après un export réussi :
1. Ouvre GitHub Desktop.
2. Vérifie les changements.
3. Commit to main.
4. Push origin.
